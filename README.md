// Crie um aplicativo mobile para cadastrar e organizar receitas culinárias do usuário. O aplicativo deve permitir adicionar, editar, excluir e visualizar receitas, além de filtrar os dados cadastrados. OBSERVAÇÃO IMPORTANTE Os dados devem ser persistidos obrigatoriamente no Firebase. Ou seja: • não basta manter os dados em variável, lista ou ArrayList; • o aplicativo deve salvar as informações no Firebase; • ao fechar e abrir novamente o app, os registros devem continuar disponíveis; • o app deve realizar operações de cadastro, consulta, edição e exclusão usando o Firebase. FUNCIONALIDADES EXIGIDAS

Cadastro de receita A aplicação deve permitir cadastrar uma receita com os seguintes campos: • Nome da receita (EditText) • Categoria (Spinner) - exemplo: Doce, Salgada, Bebida, Massa, Sobremesa • Tempo de preparo em minutos (EditText numérico) • Ingredientes principais (EditText) • Nível de dificuldade (Spinner) - exemplo: Fácil, Médio, Difícil • Receita favorita? (CheckBox ou Switch) • Salvar (Button)
Listagem O aplicativo deve exibir uma lista com as receitas cadastradas. Na listagem, mostrar pelo menos: • nome da receita • categoria • tempo de preparo • ingredientes principais • nível de dificuldade Também deve existir: • filtro por categoria com Spinner
Ações na lista • Clique curto: carregar os dados da receita nos campos para edição • Clique longo: exibir opção para excluir a receita
Validações mínimas No cadastro e na atualização: • o nome da receita não pode estar vazio;
• a categoria deve ser selecionada corretamente; • o tempo de preparo não pode estar vazio; • os ingredientes principais não podem estar vazios; • o nível de dificuldade deve ser selecionado corretamente. Caso algum dado obrigatório não seja preenchido, o app deve informar o usuário adequadamente. //
